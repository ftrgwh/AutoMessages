# 自动消息 (AutoMessages)

一款适用于 **Android 12 及以上**的定时自动发送 QQ 消息工具。到点后由无障碍服务自动打开 QQ 聊天窗口、填入消息并点击「发送」,全程无需人工操作。

> 构建产物:`app/build/outputs/apk/debug/app-debug.apk`(debug 签名,可直接安装)

## 功能

- **定时任务**:单次 / 每天 / 每周(可指定周几),到点自动向指定 QQ 号发送消息
- **聊天定位仅支持 QQ 号(纯数字)**,发送路径自动选择:
  - **① 后台直发(不打开QQ)**:通过 QQ 通知栏"快捷回复"(RemoteInput)把消息直接交给 QQ 进程后台发送,全程不把 QQ 切到前台。前提:通知栏中存在该联系人的未读消息,且能从通知中识别出该 QQ 号(对方的昵称/备注/群名片包含 QQ 号时最可靠);
  - **② QQ号直达聊天**:自动通过 `mqq://` / `mqqwpa://` 协议打开与该 QQ 号的聊天窗口 → 填消息 → 点「发送」(会短暂把 QQ 切到前台)。
  - 任务可勾选**「仅后台直发」**:绝不打开 QQ,但无法从通知识别 QQ 号时会直接失败并说明原因。
- **发送结果反馈**:每次发送成功/失败都写入任务卡片并发出系统通知,失败会附带原因和卡在哪一步
- **开机自启**:重启手机后自动恢复所有闹钟
- **单次任务自动停用**:发出后不再重复;每天/每周任务自动排下一次
- **立即发送测试**:编辑页可随时手动触发一次,验证配置是否正确

## 工作原理

```
AlarmManager(精确闹钟) → AlarmReceiver → SendDispatcher(编排)
                                            │
              ┌── ① 通知使用权(QqNotificationListener)────── 后台直发,不打开QQ
              │     按QQ号识别通知栏中的QQ会话通知 → 填 RemoteInput → 触发快捷回复
              │
              └── ② 无障碍服务(QqAutomator)─────────────── 前台回退
                    mqq:// / mqqwpa:// 协议按QQ号直达聊天窗口
                    → 无障碍节点查找:输入框填消息 → 点「发送」→ 验证输入框清空
```

- 路径①是普通 App 实现真正后台发送的唯一正规途径,依赖 QQ 通知的快捷回复能力;路径②通过无障碍服务读取/操作 QQ 窗口节点,使用文本、描述、id 关键字等宽松启发式匹配,对 QQ 版本差异有一定容忍度。
- 路径②在 Android 12 上受「后台启动 Activity」限制,需要**悬浮窗权限**才能把 QQ 切到前台。
- 任务数据以 JSON 存于 SharedPreferences,仅保存在本机,**不联网、不上传**。

## 首次使用(重要)

安装后打开 App,按顶部权限卡片的提示依次开启:

| 权限 | 作用 |
|---|---|
| 通知使用权 | 后台直发的关键:读取 QQ 通知并触发快捷回复(设置 → 通知使用权) |
| 无障碍服务 | 回退路径:自动操作 QQ 界面发送(设置 → 无障碍 → 定时发消息服务) |
| 悬浮窗权限 | 回退路径:后台把 QQ 窗口切到前台 |
| 精确闹钟 | Android 12 需在「闹钟和提醒」特殊权限页允许 |
| 通知权限 | (Android 13+ 设备才需要)接收发送结果通知 |

都就绪后,新建一个任务并点「立即发送测试」验证(先让对方给你发条消息,即可体验纯后台直发)。

## 注意事项

1. **仅支持 QQ 号定位聊天**(5-12 位纯数字),不再支持备注/昵称搜索。
2. **后台直发的前提**:通知栏里有该联系人的未读消息,且能从通知中识别出该 QQ 号;识别不到时只能走路径②。可在对方昵称或备注中加上 QQ 号以提高识别率。
3. **路径②发送时手机必须处于解锁状态**——锁屏下系统不允许操作界面,任务会失败并通知。路径①锁屏也能发。
4. 手机 QQ 必须**已登录**。路径②依赖 `mqq://` 协议,个别 QQ 版本可能限制临时会话;失败通知会写明原因。
5. QQ 大版本改版后路径②的节点结构可能变化,导致发送失败;失败通知会写明卡在哪一步,便于排查。
6. 若未授予「精确闹钟」,会退化为分钟级窗口闹钟,时间可能有少量误差。
7. 请合理使用,避免对他人造成骚扰;QQ 若弹出安全验证需人工处理。

## 构建与安装

- 用 Android Studio 打开本项目,直接 Run 即可;
- 或命令行:`./gradlew assembleDebug`(需 JDK 17+),APK 输出在 `app/build/outputs/apk/debug/`;
- 通过 adb 或文件管理器将 APK 安装到手机:`adb install -r app-debug.apk`。

## 项目结构

```
app/src/main/java/com/ftrgwh/automessages/
├── MainActivity.kt               # 入口,Compose 页面切换与刷新
├── AutoMessagesApp.kt            # 通知渠道初始化
├── data/
│   ├── Task.kt                   # 任务模型 + 下次触发时间计算
│   └── TaskStore.kt              # SharedPreferences/JSON 持久化
├── alarm/
│   ├── Scheduler.kt              # AlarmManager 精确闹钟排程
│   ├── AlarmReceiver.kt          # 到点触发:排下一次 + 派发发送
│   └── BootReceiver.kt           # 开机重排闹钟
├── auto/
│   ├── SendDispatcher.kt        # 发送编排:后台直发优先 → 无障碍回退
│   ├── QqNotificationListener.kt # 通知使用权:RemoteInput 快捷回复后台直发
│   ├── AutoSendAccessibilityService.kt  # 常驻服务:亮屏/锁屏检查/前台回退路径
│   └── QqAutomator.kt            # QQ 界面自动化(搜索/填词/点击发送)
└── ui/
    ├── TaskListScreen.kt         # 任务列表 + 权限引导卡片 + 使用指南
    └── EditTaskScreen.kt         # 新建/编辑任务表单
```
